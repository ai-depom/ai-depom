## 📋 Sobre o Projeto

O **AI-DEPOM** é um sistema completo de banco de dados policiais desenvolvido com padrões internacionais de segurança e interoperabilidade com sistemas como **FBI (NCIC)**, **Interpol (I-24/7)** e **Polícia Federal**.

### 🔐 Características Principais

| Característica | Descrição |
|----------------|-----------|
| **Criptografia** | AES-256 em repouso (TDE) com FIPS 140-2 |
| **Autenticação** | MFA com biometria facial |
| **Integridade** | Exclusão lógica (nunca deleta dados fisicamente) |
| **Auditoria** | Log completo de todas as ações |
| **Padrões** | CJIS Security Policy, LGPD, GDPR |
| **Integração** | Interpol I-24/7, FBI NCIC |
| **Armazenamento** | Azure Blob / AWS S3 com criptografia |
